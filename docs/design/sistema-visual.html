O amarelo #FFD100 é preenchimento e realce — nunca cor de texto. A tinta é #111111. No tema escuro os dois trocam de papel com a superfície: tinta com amarelo vira amarelo com tinta. Nenhuma das duas é decoração: são o idioma da marca.

Contraste medido

Mínimos da WCAG 2.1: 4,5:1 para texto e 3:1 para elemento não-textual (borda de controle, ícone que carrega informação, faixa). Os números abaixo são calculados nesta página a partir dos hex acima — se alguém mudar uma cor, a tabela muda junto.

Dois desvios deliberados do handoff, ambos por contraste medido: a borda de controle não selecionado passou de #A9A69E (2,43:1, reprovado) para #8A877F, e no tema escuro o texto sobre vermelho é tinta, não branco (branco daria 2,77:1). Nenhuma outra cor foi alterada.

O que esta tabela não enxerga: estados com opacity (botão inativo a 0,45; lista de ferramentas a 0,5; "Excluir" a 0,4) e as superfícies de vidro da tab bar e das barras de topo. Um desenho novo não pode assumir que um par aprovado aqui continua aprovado quando recebe transparência.

Tipografia

Duas famílias, empacotadas no app sob licença OFL: Archivo para interface e Literata para leitura. O peso vem da família, nunca de font-weight — em React Native combinar os dois faz o Android sintetizar negrito sobre uma face que já é negra.

Alturas de referência

Estes números são pisos, nunca medidas fixas. Toda caixa que contém texto cede ao texto: minHeight com respiro, jamais height. O texto cresce com o Dynamic Type do sistema — até 3,571× neste build — e caixa travada não acompanha: o rótulo atravessa a borda e, num botão preenchido, sai na cor da própria superfície, isto é, desaparece.
